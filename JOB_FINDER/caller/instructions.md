Caller - MCP сервис для вызовов REST API / сторонних приложений


Набор функций caller
в web_calls расположены вызовы для веб-приложений REST API
Постфикс WithNoOpts означает, что запрос будет выполнен без дополнительных параметров,
вроде хэдеров, куки

в other_calls расположены вызовы для других сущностей
например - чтение файла, запуск программы из консоли
